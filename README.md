# 🌐 Web Forensic 🔥

## 🚀 Overview
**Web Forensic** is a powerful framework designed to analyze and mitigate **Denial of Service (DoS) attacks** on web servers. This tool provides forensic insights into attack patterns and helps strengthen security against cyber threats. 🛡️💻

## 🛠️ Tech Stack
- 🐍 **Python** – The backbone of the analysis engine.
- 🐳 **Docker** – Ensures smooth and isolated execution.
- 🎯 **Curl Command** – Used for attack simulations.
- 🖥️ **CLI-based Execution** – No GUI, pure terminal power! 💪

## 🏴‍☠️ Terminology
- 🎯 **Victim:** The server targeted in the second phase of the DoS attack.
- 🌍 **ThirdPartyServer:** The initially attacked server that triggers further exploitation.
- 😈 **Attacker:** The entity exploiting vulnerabilities in the ThirdPartyServer.

## 🔥 Features
✅ **Attack Simulation** – Recreate DoS scenarios for forensic analysis.
✅ **Mitigation Strategies** – Learn and apply countermeasures against cyber threats.
✅ **Log Analysis** – Deep dive into request logs and detect anomalies.
✅ **CLI-Based Execution** – Lightweight and efficient, perfect for server environments.

## 🚀 Installation & Setup
```bash
# Clone the repository
git clone https://github.com/nimish07-ai/Web_forensic.git
cd Web_forensic

# Install dependencies
pip install -r requirements.txt

# Run the framework
python web_forensic.py
```

## 🎯 Usage
Simply execute the script and follow on-screen instructions to analyze potential DoS attacks.
```bash
python web_forensic.py --target <server-ip> --mode analyze
```
